# Contributing

Thanks for helping improve SECOND CURVE. Keep the experience calm, accessible, and evidence-based.

1. Fork the repository and create a focused branch.
2. Install Node.js 22 and run `npm ci`.
3. Run `npm run typecheck`, `npm test`, and `npm run build`.
4. Do not commit API keys, personal resumes, employer confidential data, generated build output, or signing material.
5. Describe user-facing behavior and verification in your pull request.

Career suggestions must be explainable, editable, and grounded in user-provided experience. Never invent hiring, salary, or success-rate data.
