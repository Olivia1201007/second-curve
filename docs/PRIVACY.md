# 数据安全与隐私边界

- 当前没有账号、服务端个人档案数据库或自动云同步。
- 职业经历、任务和生成草稿保存在当前浏览器或应用 WebView 的 `localStorage`。删除应用数据可能清除这些本地资料。
- 简历文件在本机 WebView 中解析；OCR 模型与 PDF/DOCX 读取依赖随应用打包的静态资源。
- 默认使用本地规则。Windows / Android 安装版可以在个人设置中配置并主动启用云模型；启用后，点击经历分析、岗位对照或经历润色，会将本次所选的文字发送到所配置的模型平台。关闭后恢复本地规则。文件解析与 OCR 本身仍在设备内完成。
- 云模型仅接收完成当前任务所需的文字，不自动上传文件、整个历史或其他档案。发送前做手机号、邮箱和身份证号的基础脱敏；这不等于完整匿名化，请主动删除姓名、单位机密等不必要内容。
- 安装包不内置团队共享 API Key。由每台设备自行配置；Windows 使用系统凭据管理器，Android 使用 AndroidKeyStore 加密保存。密钥不会返回界面或写入 localStorage；输入密钥时会短暂存在界面内存，保存后清空输入框。设备本身被控制时，不能保证密钥绝对安全。
- 模型请求由软件原生模块直接发送到配置的 HTTPS 模型平台，不经过另一个项目服务器。服务商的处理、存储和计费规则以对应平台为准。更换平台或接口地址必须重新填写密钥，避免将旧密钥发送到新地址。
- 设置中可随时关闭云模型或清除本机模型配置。清除不会撤销供应商平台的密钥，如有泄露需在模型平台撤销。重置求职体验数据与清除模型配置是两个独立动作。
- 外部招聘平台链接离开本应用后，适用对应平台隐私政策和网络可达性。
