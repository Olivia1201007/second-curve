# 数据安全与隐私边界

- 当前没有账号、服务端个人档案数据库或自动云同步。
- 职业经历、任务和生成草稿保存在当前浏览器或应用 WebView 的 `localStorage`。删除应用数据可能清除这些本地资料。
- 简历文件在本机 WebView 中解析；OCR 模型与 PDF/DOCX 读取依赖随应用打包的静态资源。
- 当前没有真实 AI 接口。不要假设用户简历已经发送给模型；本版不会远程传送简历做 AI 推理。
- Android 与桌面包不内置模型 API key。将来接入模型或云服务前，需在服务端完成 API 代理、隐私告知、数据最小化、权限校验与删除机制。
- 外部招聘平台链接离开本应用后，适用对应平台隐私政策和网络可达性。
