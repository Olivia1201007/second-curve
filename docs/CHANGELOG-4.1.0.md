# 4.1.0 变更

- Windows Tauri 增加 Rust 原生 HTTPS 模型调用与系统凭据管理器存储。
- Android Capacitor 增加 Java 原生模型插件与 AndroidKeyStore 加密存储，关闭应用备份。
- 个人中心增加看山、DeepSeek、Kimi 的地址、模型、密钥配置及明确启用/关闭/清除操作。
- 经历分析、招聘对照和经历表达接入云模型，并校验结构与用户原文依据；其他规划、面试结构与模板草稿仍为本机规则。
- 密钥不返回前端，不写入 localStorage 或安装包；更换供应商/地址要求重新输入密钥。
- 发送前基础脱敏，界面标明文字发送范围与结果来源；失败显示错误，不伪装为本机生成的成功结果。
- 保留无密钥本机模式及普通网页预览。无需独立 Python 后端或项目云服务器。

看山凭证未取得，真实接口协议与调用尚待验收；未增加知乎搜索、实时职位、工资数据、账号或云同步。
