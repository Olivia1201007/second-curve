# 评委体验指南（4.1.0）

1. 安装 Windows 或 Android 体验包，或在普通网页查看本机模式。
2. 新用户从空白档案开始；也可主动加载有明确标记的演示数据。
3. 填写经历并整理，查看带原文依据的任务与技能线索；方向建议仍为本机规则。
4. 粘贴一段真实招聘描述，查看要求、依据和待补充项；结果不代表录用概率。
5. 整理经历表达，修改草稿并管理面试练习、行动计划与岗位进度。
6. 若有本人模型凭证，在安装版的「个人中心 → 云模型设置」配置地址/模型/Key，保存后主动启用，再重复上述三个整理功能。使用不含真实个人信息的演示文本。
7. 说明边界：联网云模型由设备原生模块直连；其他规划仍在本机。没有知乎自动检索、实时岗位或工资数据库。看山尚未完成真实凭证验收。
