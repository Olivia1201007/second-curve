# SECOND CURVE 3.0 产品与比赛方案

## 问题与目标

35–55 岁求职者常需在短时间内把多年经验转译成新岗位能理解的能力，同时处理收入时间、地域、家庭安排和数字工具门槛。产品把任务控制在小步、可编辑、可暂停的求职动作中，不将年龄作为能力判断依据，也不把求职结果归因于个人价值。

## 核心流程

1. **了解情况**：记录岗位、工作内容、地点、时间与求职约束；支持本地简历导入。
2. **整理经验**：将用户描述拆为任务、能力线索、AI 可辅助的重复环节与仍需人工判断的部分；每项能力显示原文证据供确认。
3. **寻找工作**：给出经验延续、能力升级、相邻探索三类可验证方向；用户粘贴真实岗位后做文本对照。
4. **开始求职**：生成可编辑材料，练习面试，安排行动任务，记录真实岗位进度。

## 差异化与边界

经验迁移从“做过什么任务”出发，避免把整份职业笼统归为会被自动化。AI 建议需展示依据、缺口与不确定性。所有结果供用户修改，不生成虚构业绩、职位或录用概率。职业 1/3/5 年视图是讨论与验证框架，不是预测。

## 数据真实性

目前部署是静态演示/本地产品版本：知乎开放平台、招聘 API、薪资数据和真实 AI 均未连接。外链只指向平台官网；岗位由用户自行查阅并粘贴。匹配仅对用户提供的文本做本地关键词提示，不构成正式评分。工资分析在没有用户提供的真实招聘样本前不提供数值结论。

接入外部资料时需为每条记录保存来源类型、来源名称、原始 URL、抓取/录入时间、原文或授权范围、有效状态及用户核验状态。展示时明确区分官方资料、招聘方发布信息、社区经验与模型推理；社区观点不可表述为官方事实。

## 数据与隐私

现版档案、任务、岗位跟进和草稿存于浏览器 localStorage，不跨设备同步；简历文件在本机浏览器解析。删除资料会清除以 `sc-` 开头的本地键。公共网站访问本身不意味着其他访客能读取当前浏览器档案。

## 交付边界及后续

已实现本地端到端演示和来源诚实标识；未实现服务端账户、数据库、数据采集、知乎 API、真实模型、市场薪资统计和外部岗位自动同步。参赛时应演示本机可交互流程，并展示本文件中的真实边界。收到正式授权和凭证后再启用后端适配器及缓存/频控。
