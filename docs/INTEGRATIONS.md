# 外部服务接入状态（4.1.0）

| 能力            | 当前实现与边界                                                                 |
| --------------- | ------------------------------------------------------------------------------ |
| 看山云模型      | 已预留可配置原生适配器；尚未领取额度/凭证，Base URL 与模型 ID 待填写，未真调用 |
| DeepSeek / Kimi | 原生配置入口与供应商参数适配；必须填写本人有权限的模型 ID 和 Key               |
| 知乎内容检索    | 尚未接入，和看山模型调用是独立权限与接口                                       |
| 招聘 / 工资数据 | 无数据 API；岗位由用户自行查阅、粘贴并核实                                     |
| 账号 / 云同步   | 未实现；档案与草稿留在本机                                                     |

安装版直接由原生 HTTPS 访问供应商。每台设备在设置中配置自己的密钥，保存后主动启用；不需要 `.env` 或项目服务器。默认不开启云模型，普通网页继续使用本机规则。

模型适配器当前采用 Bearer API Key + Chat Completions 兼容协议。看山领取额度后，应以工作台的调用示例核对地址、模型权限、字段与响应，完成一次不含个人信息的最小请求验收。预置的 DeepSeek / Kimi 地址和模型名是可编辑值，实际可用性以账号权限及供应商最新文档为准。

知乎检索由独立模块负责，当前没有自动搜索或抓帖行为。后续取得授权后，为每条资料记录来源类型、原始 URL、发布时间、采集时间和有效性；社区经验须标明个人观点，不能混同官方就业结论。不要将知乎 OAuth 凭证当作模型 Key。
