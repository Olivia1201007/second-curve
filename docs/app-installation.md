# Android 安装指南

GitHub Release workflow 产物为 `app-debug.apk`，采用 Android debug 签名，适合评委和开发测试。下载 APK 后，在 Android 系统提示下允许本次从文件来源安装，然后点按安装。正式公开分发需配置组织的正式签名证书并重新构建。不要把正式 keystore 或密码放进 Git。

本应用将 Web 静态资源和 OCR 资源打入 APK；首次启动核心页面不需要连接线上网站。职业档案留在本机应用数据中。卸载应用或清除应用数据可能删除档案。应用无需在启动时请求位置、联系人或麦克风权限；语音功能依赖用户显式点击后的系统/浏览器能力。
