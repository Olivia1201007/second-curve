# 产品说明计划书

## 社会问题与目标用户

35–55 岁失业或转型者常难以将多年任务经验转换为新岗位读得懂的能力，也会面临时间、地域、家庭和数字工具门槛。产品帮助用户梳理真实经历、确认可迁移能力并启动务实求职动作，尊重年龄与个人价值。

## 产品体验与创新

从任务级经验出发而非给整份职业贴上“会被 AI 取代”的标签。技能提示关联到用户输入证据；岗位建议解释可复用经验和需验证条件；一天先做一件小事，材料可编辑与删除。空白首页不展示虚构职业与进度。

## 技术实现现状

Web 使用 Next.js 静态导出，Capacitor 将相同资源打包为 Android，本地包可离线加载核心 UI/档案。Tauri 加载相同静态资源提供 Windows 桌面窗口。OCR/PDF/DOCX 本地读取，职业分析与匹配采用浏览器规则。

## 知乎生态契合度及数据边界

知乎官方开放平台入口见 [知乎数据开放平台](https://developer.zhihu.com/)。当前没有知乎 API 凭证/授权，不采集或展示知乎搜索结果、热榜或用户内容。未来可在取得授权后建设职业经验知识库，记录原始链接、来源类型、发布日期、采集时间和引用范围；知乎社区经验必须明确标注为个人观点，不混同官方就业数据。

## 招聘与工资

当前不接真实招聘接口或薪酬数据库。用户可以自行打开招聘平台、粘贴职位描述并保存原始链接进行匹配。没有具备代表性的经核验样本前，不提供市场工资估值。

## 落地计划

1. 评委体验包与可重复的 CI 构建。
2. 获取招聘平台与知乎数据的正式权限，先做小范围、带来源的检索试点。
3. 建设中国大陆可访问的服务端模型适配器与隐私同意流程。
4. 在取得用户同意后研究云同步，并增加导入导出与删除机制。
5. 对实际用户测试可读性、流程完成时间和求职动作是否更容易执行，不以就业结果保证做宣传。
