# 3 分钟产品演示脚本（4.1.0）

1. 打开安装版，展示空白档案与主动加载的演示数据，说明基础体验无需注册。
2. 用模拟行政经历整理任务和技能，点击原文依据，说明结果可修改。
3. 展示三个本机方向及求职约束，说明方向不是就业预测。
4. 粘贴一段真实岗位文字，展示对照结果；不把结果称为录用评分。
5. 演示经历表达、任务与岗位跟进；面试结构、行动计划仍使用本机规则。
6. 打开云模型设置，展示本机配置与主动启用流程；不要投屏真实 Key。有已验证凭证时用虚构个人信息演示一次调用，否则明确说明本次仅演示配置流程。
7. 说明软件内置原生调用模块，无需单独后端；模型在云端，联网后使用。档案留在本机，主动整理时才发送相关文字。看山真实调用和知乎检索尚待分别验收。
