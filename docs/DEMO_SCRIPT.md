# 3 分钟产品演示脚本

1. 打开线上站点，说明新用户看到的是空白档案，基础体验无需注册；点击「先看看演示数据」，确认界面标记“演示数据”。
2. 以“有 12 年行政工作经验，负责流程协调、供应商沟通、资料管理，正在寻找运营类工作”的模拟人物为例，展示经验与证据技能。
3. 展示三个方向并解释“可以复用什么、还需核实什么”；选择一个方向作为目标。
4. 粘贴一段公开招聘文本，演示关键词对照，强调它不是录用概率，也不是招聘平台评分。
5. 增加一条岗位跟进，演示状态变化与原始链接记录；展示 1/3/5 年阶段框架是可调整的规划假设。
6. 进入求职工具箱，生成简历/自我介绍草稿或每周行动，修改、复制或打印。
7. 结束时说明：当前真实 AI、知乎 API、实时岗位和薪资数据未接入；档案只保存在本机浏览器；所有就业方向须根据本人约束和真实岗位核验。
