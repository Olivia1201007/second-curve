# SECOND CURVE 技术审查（4.1.0）

| 项目     | 当前实现                                                            |
| -------- | ------------------------------------------------------------------- |
| 页面     | Next.js 16、React 19、TypeScript，静态导出到 `out/`                 |
| 软件壳   | Windows Tauri 2 / Android Capacitor 7，加载打包本地资源             |
| 模型网络 | Windows Rust / Android Java 原生 HTTPS，WebView 不直接发模型请求    |
| 密钥     | Windows Credential Manager / AndroidKeyStore 加密；前端只读配置状态 |
| 档案     | 本机 localStorage；无账号、服务器数据库或自动云同步                 |
| 文件     | PDF/DOCX/TXT/图片与 OCR 本机解析                                    |
| 业务     | 三个已有整理接口支持本机/云模式；其他规划与模板仍在本机             |
| 数据源   | 未接知乎检索、实时职位或工资数据库                                  |

静态页面可以随两个安装包离线加载，云模型需要联网和有效凭证。无需独立后端进程。原生层限制超时、并发与响应大小并禁止重定向；WebView 的网络策略不因模型接入而放宽。

业务层校验结构、来源依据和部分数字声明，发送前进行基础脱敏。上述措施不能担保内容完全正确或完全匿名化，仍需用户核实并去除不必要的敏感信息。模型请求失败保留原输入并显示错误，不静默替换结果来源。

看山平台真实调用尚待凭证和文档核实；当前实现假设其兼容 Bearer API Key + Chat Completions。普通网站未重新发布，也未做中国大陆网络覆盖测试。构建、设备测试和真实供应商验收应分别报告。
