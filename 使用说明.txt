第二曲线 · OpenAI 接入版使用说明

一、第一次使用

1. 将整个压缩包解压到电脑上的文件夹，再打开 SecondCurve-OpenAI 文件夹。
   不要在压缩包内直接运行，也不要只复制 public/index.html。

2. 安装 Python 3.10 或以上版本。
   官方下载地址：https://www.python.org/downloads/
   安装时勾选“Add Python to PATH”。本程序不需要安装其他 Python 库。
   已安装 Python 的电脑可以直接尝试下一步。

3. 准备自己的 OpenAI API Key。
   创建地址：https://platform.openai.com/api-keys
   API 账户需要有可用额度和模型访问权限；ChatGPT 订阅不等于 API 额度。

4. 双击 start.cmd。
   在弹出的终端中粘贴 API Key，然后按回车。
   输入时看不到字符或星号属于正常现象。
   Key 只用于当前服务进程，不会保存到文件或写入网页；下次启动需重新输入。
   如果直接按回车，可以预览页面，但无法使用 AI 对话和岗位匹配。

5. 浏览器会自动打开网页。保持终端窗口打开。
   默认地址：http://127.0.0.1:8787/
   如果端口被占用，会自动选择其他空闲端口，以终端显示的“浏览器地址”为准。
   浏览器没有自动打开时，将该地址复制到浏览器地址栏。

二、网页怎么用

· 规划下一步：在首页点击“我想先聊聊情况，规划下一步”，输入问题并发送。
· 上传简历：使用原有上传入口，txt / md 文件可直接读取。
· 招聘机会：使用地区、薪资、类别等筛选，或输入自身情况后点击
  “帮我从真实岗位里挑”。点击岗位卡片可查看详情，加入“我的求职”后可管理收藏。
· 我的求职：继续使用原有收藏、六点拖拽排序、导入和导出功能。
· 求职进度、个人中心：操作方式与原版一致。
· AI 回复会逐段出现，需要中止时点击“停止”。模型菜单显示服务端配置的模型。
· 结束使用：关闭终端窗口即可停止服务；仅关闭网页不会停止服务。

三、更换模型（可选）

默认模型为 gpt-4.1-mini，实际可用模型取决于你的 OpenAI 项目权限。
需要更换时，在 SecondCurve-OpenAI 文件夹的空白处右键，选择“在终端中打开”，
使用 PowerShell 执行下面的命令，然后在启动提示中输入 Key：

    $env:OPENAI_MODEL='gpt-4.1-mini'
    $env:OPENAI_MODELS='gpt-4.1-mini,gpt-4.1'
    python -B launcher.py

将引号内的模型 ID 改成你有权限使用的文本聊天模型。
如果 python 命令不可用，可以把最后一行改为 py -3 -B launcher.py。
.env.example 仅供查看配置格式，程序不会自动读取该文件。

四、常见问题

· 提示需要 Python，或窗口一闪而过：
  安装 Python 3.10 以上并勾选添加到 PATH，再重新双击 start.cmd。
  也可在当前文件夹的终端执行 py -3 -B launcher.py 查看错误信息。

· 提示“尚未配置 OPENAI_API_KEY”：
  关闭服务后重新双击 start.cmd，输入 Key 后按回车。

· 提示 Key 无效：
  检查是否完整复制了 OpenAI API Key，确认 Key 未被撤销，再重启服务输入。

· 提示额度不足、请求频繁或模型无权访问：
  检查 OpenAI 平台的余额、用量限制和模型权限；稍后重试或更换可用模型。

· 提示无法连接 OpenAI：
  确认终端仍在运行，且运行本程序的电脑能够访问 api.openai.com。

· 双击 HTML 后 AI 功能不可用：
  请通过 start.cmd 启动，并访问终端给出的本地网址。这个版本包含网页和服务端，
  仅上传 HTML 到 WorkBuddy 静态资料库不能提供 OpenAI 接口服务。

· 新版没有原版的收藏或资料：
  数据保存在当前浏览器对应网址的本地存储中；WorkBuddy 与本地网址互不共享。
  原版收藏可通过“我的求职”导出，再在新版同处导入。其他资料请保留原版备份。
  更换浏览器、端口或清除站点数据，也可能看到不同的本地数据。
  尽量固定浏览器和网址，并定期使用网页内的导出/备份功能。

五、数据与部署

主动提交给 AI 的文字，以及请求中附带的简历或岗位内容，会通过服务端发送至 OpenAI。
服务端不记录请求正文和密钥；分享文件前不要将自己的 Key 填入文件。
默认服务仅供本机访问。如需提供公开网址，需要另行部署服务端，并配置 HTTPS、
同源反向代理和访问控制；详细配置请阅读同目录 README.md。

本版已通过接口自动测试和本地模拟流程验证。真实 OpenAI 连通性、账户权限及费用，
以你配置自己的 API Key 后的实际调用为准。
